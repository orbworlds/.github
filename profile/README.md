# Orb

**Make games and worlds by talking.** Say what you want ("a castle on a cloud with friendly
dragons") and watch Orb build it. Every world gets a link, loads instantly in any browser, is
played together, and can be remixed by anyone. → **[orbworlds.com](https://orbworlds.com/?utm_source=github&utm_medium=profile)**
